# 03 — AI and Agent Governance

FinAgent uses controlled capabilities, model and tool gateways, evidence references, and deterministic checks to support human investigation. Model-generated content is a draft; validation does not prove factual accuracy. The experimental assistant candidate remains disabled in the current development configuration.
